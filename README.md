# ai-voiceassistant-py-win
A little fun-project. With the voiceassistant you have a funny new companion on your computer, that you can talk to. It registers you per OpenAI-Whisper and is very flexible, because you can choose the LM, with which you want to communicate! I made it this way, so that also people with garbage PC´s can run this.
Also your communication-partner is displayed by a little cat icon on your desktop. Am planning on more Custom-Icons and the option to remove the icon. 
I forgot to mention, that everything is free! You can just download what you need for no monetas. You will need python, whisper, LM studio, a few other dependencies, I´ll finish this readme later, Im tired!
